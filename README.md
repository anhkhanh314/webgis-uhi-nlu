# WebGIS UHI TP.HCM

## Mục tiêu
Xây dựng hệ thống WebGIS giám sát nhiệt độ bề mặt và hiệu ứng đảo nhiệt đô thị tại TP.HCM bằng dữ liệu viễn thám.

---

## Công nghệ sử dụng
- Frontend: Leaflet
- Backend: PostGIS + GeoServer
- Viễn thám: Google Earth Engine
- Database: PostgreSQL
